# 04 GUI MVP（まず作る画面）

## 画面1枚で足りるもの
1. **チャット欄**（ユーザー / 瞳）
2. **ステータスパネル**（trust / affection / obedience などバー表示）
3. **イベントボタン**（調教・親密・褒め・叱る・セーフワード）
   - 実機の「接触」の代わり。後でセンサーイベントに置換
4. **ユーザー切替**（Aさん/Bさんで別メモリ）
5. **生ログ**（promptに何を載せたかデバッグ表示・折りたたみ）

## 操作フロー
1. ユーザー選択 or 新規
2. 会話する → LLM応答
3. イベントボタンを押す → ステート更新 → 次の応答トーンが変わることを確認
4. 再起動後も同じユーザーなら記憶が残ることを確認

## 技術候補
- 最速: Gradio ChatInterface + sidebar
- 拡張しやすい: FastAPI + シンプルHTML/HTMX または Tauri/Electron
- 既存LocalAI連携: Open WebUIは汎用すぎるので、瞳専用GUIの方が実験しやすい

## 受け入れ基準（プロトタイプ完了の目安）
- [ ] 同一ユーザーで10往復しても口調が破綻しにくい
- [ ] イベント連打でステートが変わり、拒否/受容のトーンが変わる
- [ ] 別ユーザーでは記憶が混ざらない
- [ ] セーフワードで即座にモードが落ちる
