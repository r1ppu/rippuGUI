# 01 プロジェクトブリーフ（瞳 / rippuGUI）

## 一言
リアルに会話も親密な接触もできる、調教型ヒューマノイド「瞳」。

## 詳細（プロダクト意図）
「瞳」は、動かない既存ラブドールと、画面の中だけの会話AIのあいだを埋める存在です。会話し、体温を持ち、表情を変え、身体的なインタラクションが可能です。ユーザーは調教を通じて反応（セクハラや親密行為への応答）を変化させ、ユーザーごとの「瞳」を育てます。入り口はエロだが、支配欲求の安全な捌け口として自己理解を助け、健全な人間関係に戻るための装置でもある、という位置づけです。

## このリポジトリ（rippuGUI）の役割
- いまは **ヒューマノイド本体ではなくプロトタイプ**
- **GUI実装**で、会話AIの機能を先に試す
- 検証したいこと（優先）:
  1. キャラ一貫性（瞳らしさ）
  2. 短期会話の自然さ
  3. 「調教」による長期的な反応変化（ステートマシン / メモリ）
  4. ユーザーごとの差分の保存・読込
  5. 将来の実機I/F（発話・表情・接触イベント）を想定したイベントログ

## 非ゴール（いまはやらない）
- 実機メカ・センサー統合の完成
- クラウド必須のサービス化
- 未成年人を扱うコンテンツ（対象は成人のみ）
